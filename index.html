Mini Compiler Lab

Type an arithmetic expression and watch it travel through a real compiler pipeline: tokens, syntax tree, optimizer, bytecode, virtual machine.

Lexer: tokens

The text is split into meaningful pieces.

Parser: syntax tree

Precedence is encoded by depth: deeper nodes run first.

Optimizer: after folding

Sub-trees made only of numbers are computed at compile time.

Code generator: bytecode

A post-order walk of the tree gives stack-machine instructions.

Grammar

Each rule is one function in the parser. Lower rules bind tighter.

expr  -> term  (('+' | '-') term)*
term  -> unary (('*' | '/' | '%') unary)*
unary -> '-' unary | power
power -> atom ('^' unary)?        right-associative
atom  -> NUMBER | '(' expr ')'
